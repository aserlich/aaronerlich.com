# Files Directory

Place your downloadable files here:

- `Erlich_CV.pdf` - Your CV PDF
- `paper_advice.pdf` - Your writing advice PDF (currently linked from old site)
- Any other PDFs, datasets, or files you want to share

These files will be accessible at relative URLs like:
- `files/Erlich_CV.pdf`
- `files/paper_advice.pdf`

## Important for GitHub

Make sure to commit these files to git so they're included in your repository!

```bash
git add files/
git commit -m "Add CV and other files"
git push
```
